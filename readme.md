# Programación III

**Autor:** Darío Guayasamín Saul Defas

## Descripción

Este repositorio contiene las prácticas, ejercicios y proyectos realizados durante la materia de **Programación III**. Se trabajarán diferentes tecnologías orientadas al desarrollo web, desde los fundamentos de una página hasta el desarrollo de aplicaciones modernas.

## Tecnologías y conceptos

### HTML

Lenguaje utilizado para crear la estructura y contenido de las páginas web, como títulos, textos, formularios, imágenes y enlaces.

### CSS

Lenguaje utilizado para dar estilos y diseño a las páginas web, permitiendo trabajar con colores, tamaños, posiciones, diseños y adaptabilidad.

### JavaScript

Lenguaje de programación utilizado para agregar interactividad y comportamiento dinámico a las páginas y aplicaciones web.

### TypeScript

Lenguaje basado en JavaScript que agrega tipado estático y otras características que ayudan a desarrollar aplicaciones más organizadas y fáciles de mantener.

### NestJS

Framework de Node.js basado en TypeScript utilizado principalmente para desarrollar el backend y crear APIs y aplicaciones del lado del servidor.

### ReactJS

Biblioteca de JavaScript utilizada para crear interfaces de usuario mediante componentes reutilizables y dinámicos.

## Contenido

En este repositorio se irán almacenando las diferentes actividades realizadas durante el curso, incluyendo ejercicios, prácticas y proyectos relacionados con las tecnologías estudiadas.

## Objetivo

Aplicar los conocimientos adquiridos en **Programación III** para desarrollar aplicaciones web utilizando tecnologías modernas de frontend y backend.
